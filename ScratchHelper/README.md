# ScratchHelper

Modular Roblox reference-image overlay with GitHub-hosted PNG downloads.

## Add images
1. Upload a PNG to `ScratchHelper/Images/`.
2. Add its exact filename to `ScratchHelper/Images/manifest.txt`.
3. In the script, refresh the list and select **Download + load selected**.

## Requirements
Executor must support `game:HttpGet`, `loadstring`, `isfolder`, `makefolder`, `writefile`, `listfiles`, and `getcustomasset` or `getsynasset`.

## Visibility
This repository is private at creation time. Anonymous GitHub Raw requests will not work until the repository is made public or an authenticated download method is implemented.
